# 02. Historias de usuario

Las historias HU-01 a HU-10 vienen de la v2.0 y se ajustaron al juego. Las historias HU-11 a HU-22 son nuevas.

| Código | Historia | Prioridad |
| --- | --- | --- |
| HU-01 | Como estudiante, quiero entrar eligiendo mi avatar y escribiendo mi PIN para jugar con mi propio avance. | P1 |
| HU-02 | Como estudiante, quiero ver las explicaciones del guía y las fichas sin internet para aprender en el aula. | P1 |
| HU-03 | Como estudiante, quiero recibir una explicación inmediata en cada respuesta para entender mis errores. | P1 |
| HU-04 | Como estudiante, quiero rendir el desafío final del módulo para conocer mi calificación. | P1 |
| HU-05 | Como estudiante, quiero retomar un nivel donde lo dejé para no perder mi avance. | P1 |
| HU-06 | Como docente, quiero descargar un módulo completo una sola vez para no depender de internet en el aula. | P1 |
| HU-07 | Como docente, quiero registrar a mis estudiantes en la tablet para que cada uno tenga su avance. | P1 |
| HU-08 | Como docente, quiero ver en cada tablet las estrellas y las calificaciones de mis estudiantes para registrar su desempeño. | P1 |
| HU-09 | Como docente, quiero habilitar el siguiente módulo cuando el grupo esté listo. | P1 |
| HU-10 | Como docente de otra escuela, quiero configurar la aplicación con los datos de mi institución para usarla con mis estudiantes. | P1 |
| HU-11 | Como estudiante, quiero recorrer un mapa por capítulos (Sierra, Selva y Costa) para elegir mi siguiente nivel. | P1 |
| HU-12 | Como estudiante, quiero que mi personaje avance con cada respuesta correcta y escape de Atoq para que practicar sea emocionante. | P1 |
| HU-13 | Como estudiante, quiero tener vidas y volver a intentar el nivel cuando las pierdo para aprender de mis errores. | P1 |
| HU-14 | Como estudiante, quiero ganar de una a tres estrellas por nivel para saber qué tan bien lo hice. | P1 |
| HU-15 | Como estudiante, quiero que el guía me explique con diálogos cuando lo necesito y reaccione a mis respuestas. | P1 |
| HU-16 | Como estudiante, quiero leer textos, tablas y gráficos y responder preguntas con el texto a la vista. | P1 |
| HU-17 | Como estudiante, quiero personalizar mi avatar y coleccionar insignias y cartas para ver mi progreso. | P2 |
| HU-18 | Como docente, quiero crear retos en el panel web con preguntas sobre un tema concreto para reforzar lo que necesita mi clase. | P1 |
| HU-19 | Como docente, quiero descargar en las tablets los retos que publiqué y habilitarlos para mi sección. | P1 |
| HU-20 | Como docente, quiero ver la calificación AD, A, B o C de cada estudiante por módulo. | P1 |
| HU-21 | Como docente, quiero exportar un reto o un módulo a un archivo para instalarlo por USB en escuelas sin conexión. | P2 |
| HU-22 | Como integrante del equipo de contenidos, quiero publicar los módulos oficiales en el catálogo para que cualquier escuela los descargue. | P1 |

## Criterio transversal

Todas las historias de uso en el aula deben funcionar sin internet. Las únicas excepciones son la consulta del catálogo, la descarga de paquetes y el uso del panel web.
